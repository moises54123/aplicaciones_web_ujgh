# Ejercicio 6: Factura

Formulario (`index.html`) donde se ingresa la descripción del artículo, la cantidad y el precio unitario. `factura.php` calcula:

- Subtotal = cantidad × precio unitario.
- IVA del 12% sobre el subtotal.
- Si el total con IVA supera 150 $, se aplica un descuento del 15%.
- Muestra el desglose y el total neto a pagar.

Para usarlo, abre `http://localhost/Aplicaciones%20web/ejercicio6_factura/` con XAMPP encendido.
