# Ejercicio 5: Sueldo quincenal

Formulario (`index.html`) donde se ingresa el nombre, la cédula y las horas trabajadas en cada turno. `sueldo.php` calcula:

- Sueldo bruto: diurna 675 Bs./h, vespertina 700 Bs./h, nocturna 956.23 Bs./h.
- Retenciones según el sueldo bruto:
  - Menor a 85,000 Bs.: Ahorro Habitacional 0.1%, Seguro Social 0.15%.
  - Entre 85,000 y 150,000 Bs.: Ahorro Habitacional 0.15%, Seguro Social 0.2%.
  - Mayor a 150,000 Bs.: Ahorro Habitacional 0.3%, Seguro Social 0.25%.
- Sueldo neto = bruto − retenciones.

Para usarlo, abre `http://localhost/Aplicaciones%20web/ejercicio5_sueldo/` con XAMPP encendido.
